# 复制给接手 Agent

你将接手有序Orbit项目。请先阅读AGENTS.md、PROGRESS.md、planning/backlog.json，以及最近里程碑涉及的文档。检查当前代码、分支、未提交改动、迁移和实际脚本，不假定上一位Agent的所有结论都已验证。

先用简短状态说明指出：已完成的真实流程、当前任务与依赖、关键验证证据、未解决问题。然后继续当前已授权范围内最接近完成的一项任务。无需从头重建或大规模重构。

接口以contracts/openapi.json为准，权限/数据规则见docs/01与04。遇到规格冲突，提出并落实最小一致修正，同步相关文件和测试。保留用户改动，不清空数据或覆盖未完成工作。

任务完成后更新PROGRESS和backlog，并给出下一位Agent无需对话历史即可继续的交接记录。不要把凭证、邀请token、signed URL或私人数据放进交接文本。
