# 02 · 页面、交互与视觉规范

## 1. 设计方向

Orbit 的气质是清晰、安静、可信，视觉语言接近 Apple 的液态玻璃：导航和控件是浮在内容上方的半透明材质，内容保持简单、易读。主要视觉仍来自排版、对齐、留白和状态反馈。避免无信息价值的装饰、夸张动效，以及让正文失去可读性的透明度。

玻璃只用于浮层和导航层（侧栏、分区胶囊、标签栏、弹层、任务面板）。内容层用不做实时模糊的半透明卡片，保证大看板流畅。深色模式跟随系统；系统要求降低透明度或浏览器不支持模糊时退回实色。

官网仅用于学习信息层级与克制用色。自行绘制 Orbit 字标/简洁轨道线图形，不使用他人品牌素材。V1 无需 ImageGen 图片或复杂插画；空状态使用简单线形图标配操作引导。

## 2. Design tokens

变量和取值以 `src/styles/tokens.css` 与 `src/styles/glass.css` 为准，这里只记录规则。

- 正文对比度达到 WCAG AA 4.5:1，大字号 3:1，空输入框边界与焦点环 3:1。修改 token 后重新计算，并在 tokens.css 头部更新实测值。
- 填充色与文字色分开：`brand`、`danger-fill` 作为白字的底，`brand-ink`、`success`、`warning`、`danger` 用于文字和图标。
- 字号：12（辅助）、13（脚注）、14（标签、任务卡）、16（正文）、17（卡片标题、项目名）、20（区域标题）、26—32（页面标题）、40—80（介绍页主标题）。手机输入框不低于 16px。中文标题的字距收紧幅度小于英文。
- 字体用系统字体栈，不下载中文字体。
- 圆角同心递进：输入框 12、菜单项与侧栏项 14、任务卡 16、内容卡与看板列 22、侧栏与浮层 28，按钮和分段控件为胶囊形。
- 间距基数 4。常规控件高 40，手机上的主要目标不小于 44。
- 动效 180—480ms，以 opacity/transform 为主，只做入场动画，关闭立即卸载；遵从 prefers-reduced-motion。
- 项目颜色：蓝、紫、青、绿、橙、灰 6 个固定 token，仅用于项目图标，不替代状态或权限标识。

## 4. 应用外壳

桌面 ≥1280：左侧 252px 浮动玻璃侧栏，四周留 12px，没有顶部工具栏。侧栏包含字标、我的工作台、全部项目、最近项目（最多 6 个）和底部账户。

768—1279：侧栏收窄至 72px，保留 tooltip 和可访问名称。

<768：底部浮动标签栏（工作台、项目），旁边的头像按钮打开包含最近项目与账户的底部抽屉。任务详情占满屏。看板按状态 tab 一次显示一列，通过状态菜单修改状态，无触屏拖拽要求。表格转为任务卡片，不强制全页面横向滚动。

项目页顶部一行是项目栏：左边是项目图标和项目名，右边是玻璃胶囊导航（看板、列表、活动、成员、设置，末尾是回收站图标）。邀请是成员分区里的一页，入口只对 owner 显示。项目栏吸顶，内容从它下方滚过时在滚动边缘里变糊淡出；手机上只有胶囊吸顶。看板与列表切换时保留筛选。

每页只有一个主标题。顶层页面由 PageHeader 渲染；项目内各页的主标题是项目栏里的项目名，分区用 SectionHeader 的二级标题；独立任务详情页的主标题是任务标题，项目名在那里只是上下文。

长项目名称截断并提供完整名称 tooltip/详情，不能推挤主操作。加载时外壳尺寸稳定：工作台用同形骨架屏；项目页不加 `loading.tsx`，首屏一次输出，切换时被点击的导航项显示进行中状态（`LinkLabel`）。

## 5. 页面规格

### 我的工作台

顶部显示用户时区日期和“今天，先把重要的事做好。”六个分类磁贴（全部未完成、逾期、今天到期、未来 7 天、进行中、已完成）同时是统计和筛选入口，有选中态与文本说明。正文是任务列表，展示状态、标题、编号、优先级、截止日。数据不是互斥集合，不显示误导的合计饼图。

首次无任务：“还没有分配给你的任务。创建一个项目，开始安排第一步。”操作为创建项目。任务全部完成：“今天安排的任务已完成。”不自动播放庆祝动画。

### 项目列表

卡片网格，每个项目显示图标、名称、描述摘要、成员数、未完成任务数、归档标记，整张卡片是进入看板的链接。创建项目用对话框；全局唯一 key 在提交时检查，冲突在字段旁提示。已归档项目单独 tab，默认不混入活动项目。

### 看板

│ 子任务 2/4       │    │ 评论 3           │    │                  │

任务卡内容不超过 5 行：左侧状态图形（同时是移动状态的系统菜单）、标题两行、编号/优先级/截止日/计数、负责人头像。最多一个重点色状态。高优先级和逾期分别用图标/文案，不把所有卡片都染红。鼠标可按住卡片任意位置拖动，拖拽手柄在 hover 时显示，键盘焦点时同样可见。筛选控件改动立即生效，搜索在停止输入后生效，回车立即生效。

拖拽时保留原位置占位，跨列时显示插入线并高亮目标列。拖动浮层是一片玻璃，无旋转/缩放夸张效果；屏幕阅读器用中文宣告移入列。加载不完整/筛选时禁用排序并解释原因。选中卡片在详情面板打开期间保留可辨识状态。

### 任务详情

桌面面板宽 620px，浮动在右侧，内容高度独立滚动。吸顶条放编号、复制链接、更多菜单、关闭；标题下是系统设置风格的属性组（状态、优先级、负责人、截止日）；接着描述、子任务、评论、附件。任务操作的 loading 局部展示。

面板采用模态 Drawer：桌面右侧展示、手机全屏展示，打开时焦点进入面板并隔离背景。Tab/Shift+Tab 在面板内循环；Escape、关闭按钮和点击遮罩共用未保存更改确认。关闭后恢复到触发任务卡；直链进入或跨断点导致原卡片隐藏时恢复到可见看板。独立详情 URL 保持普通页面语义。此规则于 2026-09-08 的 M0 复核修正中明确。

标题和描述进入编辑模式后出现保存/取消，保存成功后退出编辑。有未保存更改时关闭/切换任务给出“保留编辑/放弃更改”对话框。409 冲突保留草稿和原编辑版本；重新加载后同时展示远端标题、描述及本地输入。用户明确选择采用远端或保留本地后才推进版本，后续远端再变化仍返回409；获取失败保留原基准并允许重试。取消编辑不触发写请求。嵌套确认框的 Escape 只关闭最上层，保留详情与草稿并恢复触发焦点。

创建任务对话框只要求标题；项目内自动确定 projectId；其余字段逐步展开。Enter 在标题输入可提交，描述内 Enter 换行；Ctrl/Cmd+Enter 提交表单。系统快捷键不覆盖浏览器常用快捷键；V1 不做全局命令面板。

### 评论与附件

评论输入框明确“发表评论”，提交成功才清空；失败保留原文。已编辑显示时间，删除后保留占位。附件行显示文件名、格式、大小、上传者和状态；超限前端尽早提示，但以后端判断为准。上传失败提供重试/移除，不假装完成。下载失败不清空详情。

### 项目设置与回收站

设置分项目资料、成员、邀请、归档四个区域。成员能看到资料和成员列表以及自己的退出入口，管理操作只对 owner 显示。邀请 token 只在新建成功时展示一次并允许复制；已有邀请仅显示创建时间/到期时间/状态及撤销按钮，无法从服务端取回原 token。

成员退出/移除确认文案：“将取消该成员的任务分配，并保留历史讨论。”归档提示“项目将变为只读，可随时恢复”。删除任务进入回收站，提供短暂撤销入口；回收站只显示摘要，恢复权限不足不显示操作按钮。

### 介绍页与演示

介绍页一屏主张、一屏界面预览、三项功能、开始使用与只读演示即可。界面预览由真实组件和合成数据渲染，不用截图：它跟随深色模式，界面改版后不会过期；对辅助技术是一张图，内部不可聚焦。演示数据是构建时合成数据，不接入真实私有项目；/demo 所有写操作明确提示“演示模式，登录后创建自己的项目”。不提供全网共享写权限的演示账号。

## 6. 组件清单

基础：Button、IconButton、Input、Textarea、NativeSelect、Select/Combobox、Dialog、Drawer、Tooltip、DropdownMenu、Segments、PageHeader/SectionHeader、Badge、Avatar、Skeleton、Spinner、Toast、InlineError、EmptyState。列表分页用「加载更多」按钮，不设页码组件。

业务：AppShell、ProjectHeader、TaskRow、TaskCard、BoardColumn、TaskDetail、TaskEditor、MemberPicker、DueDatePicker、PriorityBadge、SubtaskList、CommentThread、AttachmentList、ActivityItem、ConflictNotice。

使用 Radix/headless 基础原语解决焦点/弹层，不另造不可访问的基础组件。样式通过 token 统一。日期选择器必须支持键盘及直接输入日期。

## 7. 必须验证的状态矩阵

| 状态 | UI 行为 |
|---|---|
| 首次加载 | 对应布局 skeleton，无明显布局跳动 |
| 后台刷新 | 保留已有内容，小范围刷新提示 |
| 真正无数据 | 解释价值并提供下一步 |
| 筛选无结果 | 显示“没有匹配任务”及清除筛选 |
| 网络失败 | 局部错误、重试、保留草稿 |
| 未登录/会话过期 | 跳登录并保留合法 returnTo，不在 URL 放私有内容 |
| 读取过于频繁 | 跳转 /rate-limited 说明页，显示约需等待的秒数与返回原页面的「重试」，不读取私有数据 |
| 无权限/不存在 | 统一不可访问页面，不泄露项目名称 |
| 项目归档 | 顶部只读提示，禁用业务写入口 |
| 版本冲突 | 保留输入、说明原因、重新加载 |
| 长中文/英文/URL | 合理折行；卡片截断，详情完整显示 |
| 减少动画 | 取消非必要过渡，状态仍清楚 |

## 8. 界面回归

在真实页面验证 390、768 和 1440px 视口、键盘操作和主流程。自动化入口见 [测试](../tests/README.md)。

### 草稿与后台刷新补充（2026-09-11）

项目/任务创建的取消、收起按钮与页面离开使用相同的未保存确认；用户拒绝放弃时保留全部输入，接受后才卸载。多个编辑作用域共享一套浏览器离开监听，单次操作只确认一次；成功保存自动关闭时不再次询问。

已有评论/子任务列表在后台网络失败或 500 时持续挂载，显示局部错误和重试；首次读取失败才显示整块错误态。远端更新不替换正在编辑的文字及原 expectedVersion。提交期间冻结对应输入，失败后恢复编辑并保留草稿。

详情关闭统一检查父任务、评论、子任务、附件选择和在途上传；明确放弃才关闭。关闭嵌套弹框、取消导航或浏览器后退不清除草稿。关闭时取消未完成上传，但不能承诺撤销已到达服务端的保存。

同账号/项目/筛选刷新重取已加载分页范围，读取期间保持内容和高度；上下文改变清空旧窗口，过期请求不得回写。看板全量加载后刷新/移动保持排序所需范围，重新读取期间禁用排序。

### 综合审查补充（2026-09-13）

最近项目按项目 updatedAt/id 倒序显示当前用户拥有或参与的六个未归档项目；只链接真实看板。首次加载提示、失败清空旧项目并重试、空态指向全部项目；路由变化、恢复焦点和每30秒重取，状态不跨用户共享。手机看板 tab 与 panel 通过 ID 关联，只有选中 tab 可 Tab 聚焦，方向键循环、Home/End 到首尾；桌面恢复三个具名区域。公开 /demo 使用明确显示的固定日期快照以稳定展示逾期/今天/临近状态。

### 草稿、删除与导航补充（2026-09-24）

任务标题/描述草稿在本机保存 7 天，只为刷新、崩溃或会话过期后恢复。打开任务时若存在本机草稿，显示「本机保存了未提交的…草稿」提示，提供「继续编辑草稿」与「删除本机草稿」；恢复时草稿包含的全部字段同时处于编辑态并提示核对，只出现一组保存/取消，不存在看不见却会被提交的字段。取消、在「保留编辑/放弃更改」中放弃、确认离开页面或保存成功都会删除该草稿；刷新和关闭标签页保留。退出登录成功才删除该用户全部草稿，取消或失败保留；同一浏览器换账号时删除其他账号的草稿；退出项目或失去项目访问时删除该项目草稿。

打开中的任务在别处被删除后，看板/列表保持可用，面板保留最后内容与评论等草稿，顶部显示「该任务已被删除或你已失去访问权限」且标题/描述/属性只读，关闭仍走未保存确认。直接打开失效的 `?task=` 链接显示「任务不存在或已被删除」面板；独立详情页在项目可访问时同样显示该说明，项目不可访问仍为统一不可访问页。

浏览器后退/前进的兼容路径（无 Navigation API）以当前所在历史条目判断是否离开，取消时恢复该条目；只改变 hash 的链接（如「跳到主内容」）不触发离开确认。

独立详情页的任务标题为页面 h1，侧面板中为 h2；描述中的 Markdown 标题从 h3 起，视觉字号不变。
