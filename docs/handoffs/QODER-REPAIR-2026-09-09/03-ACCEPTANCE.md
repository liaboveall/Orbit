## 最终命令与证据

从仓库根目录执行，记录**最终退出码**：

```powershell
pnpm check
pnpm build
pnpm test:integration
$env:E2E_BASE_URL = 'http://localhost:3000'
pnpm test:e2e --output artifacts/qoder-repair-verification/e2e-results
pnpm test:ui --output artifacts/qoder-repair-verification/ui-results
```

- 启服务前确认实际端口、受信Origin、数据库与Mailpit可用；不要输出.env或会话值。上述Origin按当前本地配置，环境改变时先核验。
- check已经包含lint/typecheck/unit/contract；全部通过后，无新增修改不必重复消耗同一轮检查。build的整体exit0才是成功。
- Prisma generate、迁移和配置写入不要并行；UI/E2E如果并行必须分开输出目录，避免trace互相覆盖。
- 数据库迁移只对核验过的独立测试库应用，不执行reset/清库；结束清理本次合成数据。
- 每条A/BASE记录至少一个正式测试位置或精确手动步骤、预期、实际、环境、证据。未运行=未运行，失败=失败，不能用“总体通过率高”代替。
- 最终针对完成后的同一份代码核验；若验收过程中其他专家继续修改相关文件，需要重跑受影响检查。
