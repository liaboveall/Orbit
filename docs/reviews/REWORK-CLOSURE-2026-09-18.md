## 完成的修复

1. 治理探针仅复制允许的源文件，不复制环境配置/密钥，使用自动清理的临时目录。V1 里程碑归属固定，发布完成需逐类验证证据；补充真实的失败探针。
2. 契约测试独立绑定 37 个 operation 的 DTO/状态/信封，比较实际 Zod 参数与 OpenAPI；9 种契约破坏均由同一比较器拒绝。签名下载参数也使用实际运行时 schema。
3. 池恢复测试无论断言是否成功都释放连接并关闭池；受控断言失败探针确认错误传播和两项清理。
4. `/api/v1` 根路径和未知子路径返回 JSON；真实服务器验证既有路由优先级与 HEAD 空体。
5. 邀请令牌维护使用 `--execute --target=<预览指纹>`，绑定环境、主机/端口、数据库及脚本范围。只读约束检查只输出数量；旧参数被拒绝，集成测试验证事务清理与不触及无关记录。
6. 容器冒烟使用合成数据库的 Docker 私有网络与一次性代理，移除 Desktop 专属主机地址假设；CI 实际启动镜像并测试依赖失败/恢复。
7. 单机部署模板移至 `infra/compose.micro.yml`，文档引用该真源；外部数据库模板有独立用途，两者均限制日志增长。备份校验已进入 CI。
8. Dialog 在组合 Escape 时阻止弹层监听传播，保留原生默认行为；浏览器覆盖对话框不误关、组合结束可关闭和设置页 200% CSS 缩放。历史状态标题已归位，当前入口由 backlog 生成。
